A promo code is a discount code with your name on it. A customer types it in at checkout, they get money off, and the sale is credited to you.

It's the easiest thing you can share, because there's nothing to click and nothing to break. You can say it out loud in a video, print it on a flyer or drop it in a caption, and it still tracks.

<Note>
  Not every program uses codes. If you don't see a codes section anywhere in your portal, yours tracks by link only. See [your referral links](/help-center/affiliates/referral-links).
</Note>

## Find your code

The quickest way is the **Promote** button in the top right of the affiliate portal. Your codes appear in the **Your Discount Code** section of the window that opens, under your link.

![promo-code-in-promote-dialog](https://qnthgdfusotvjgaxpfie.supabase.co/storage/v1/object/public/public-assets/docs/uploads/1784822809123-627595-final-promo-code-in-promote-dialog-1784822809021.png)

For the fuller view, open **Settings** in the left sidebar, go to the **Personal Information** tab, then **Promo Codes**. This page lists every code you have with its discount, how many times it's been used and when it runs out.

![promo-codes-settings](https://qnthgdfusotvjgaxpfie.supabase.co/storage/v1/object/public/public-assets/docs/uploads/1784822115122-502139-final-promo-codes-settings-1784822114889.png)

Either way, the copy icon on the right puts the code on your clipboard and shows a **Code copied!** confirmation.

## Read what's on a code

Each code card packs a lot into a small space.

![promo-code-card-anatomy](https://qnthgdfusotvjgaxpfie.supabase.co/storage/v1/object/public/public-assets/docs/uploads/1784821155237-493791-final-promo-code-card-anatomy-1784821155064.png)

| What you see | What it means |
| --- | --- |
| The code in bold | What the customer types at checkout |
| `12 redeemed` | How many customers have used it so far |
| `12/100 redeemed` | The same, but the program capped it at 100 uses |
| **Auto-generated** | The program created this one for you, you didn't |
| `20% off (one-time)` | The discount, applied to the first payment only |
| `20% off for 3 months` | The discount repeats for that many months |
| `20% off forever` | The discount applies for as long as they stay subscribed |
| `Expires Mar 4, 2026` | The last day a customer can redeem it |

The **one-time**, **for x months** and **forever** wording only matters for subscription products. For a one-off purchase, the customer gets the discount on that order.

<Warning>
  Once a capped code hits its limit, it stops working at checkout even though it still appears in your portal. Keep an eye on the redeemed count if you're running a big push, and ask your program manager to raise the cap before it runs out.
</Warning>

## Create your own code

Some programs let you name your own code, which is worth doing because a code people can remember gets used far more than a random string.

If a **Create Promo Code** button appears at the top right of the **Promo Codes** page, you can make one. If it isn't there, the program hasn't opened any discounts up for self-service, or you've already made as many as you're allowed. Ask your program manager to add one for you.

![create-promo-code-form](https://qnthgdfusotvjgaxpfie.supabase.co/storage/v1/object/public/public-assets/docs/uploads/1784821153198-684812-final-create-promo-code-form-1784821152936.png)

<Steps>
  <Step title="Select Create Promo Code">
    A **New Promo Code** panel opens.
  </Step>
  <Step title="Pick a discount">
    Open the **Select a coupon** dropdown. Each option shows the discount name, how much money it takes off, and a count in brackets like `0/2`. That count is how many codes you've already made on that discount out of the total you're allowed.
  </Step>
  <Step title="Type your code">
    Use letters and numbers only, like `SARAH20`. Spaces, hyphens and symbols are removed as you type, and everything is turned into capitals. Your code has to be unique within the program, so if someone already took it you'll be told when you save.
  </Step>
  <Step title="Select Save">
    The code appears in your list and works at checkout straight away.
  </Step>
</Steps>

A short, obvious code beats a clever one. Your name or handle plus the discount amount is a reliable pattern, and it's easy for your audience to remember from a video.

The program can attach conditions to a discount, such as a minimum order value, an expiry date or a cap on total redemptions. Those come from the discount you picked, so they apply to your code too and you'll see them on the card once it's created.

## Delete a code you made

Codes you created yourself have a trash icon next to the copy icon. Select it, then confirm in the **Delete Promo Code** window.

Codes the program assigned to you don't have a trash icon, because only your program manager can remove those.

<Warning>
  Deleting is permanent, and it stops the code working at checkout immediately. If the code is live in a video, a post or anything printed, leave it alone. Anyone who tries it afterwards gets an error, and you lose the sale.
</Warning>

## When a code is attached to your link

Some programs connect a code to your referral link so the discount is filled in automatically. When that's set up, you'll see a small green tag under the link on your **Affiliate Links** page showing the code and what it takes off.

![linked-code-auto-apply](https://qnthgdfusotvjgaxpfie.supabase.co/storage/v1/object/public/public-assets/docs/uploads/1784821154470-286945-final-linked-code-auto-apply-1784821154293.png)

Anyone who arrives through that link gets the discount applied at checkout without typing anything. This is normally your highest-converting option, so lead with the link when you have one, and keep the code itself for places where a link doesn't work, like a podcast read or a printed insert.

## How a code gets credited to you

A code doesn't rely on cookies or on the customer clicking anything. When they enter it at checkout, the program matches the code to you and the commission is yours.

That has some useful consequences:

- **It survives everything a link doesn't.** Private browsing, cleared cookies, a different device, a purchase weeks after they first heard about you.
- **It works offline.** Spoken in a video, printed on packaging, written on a card in a box.
- **It doesn't expire the way a click does.** There's no tracking window to beat, only the code's own expiry date if it has one.

The trade-off is that the customer has to remember to enter it. That's why sharing both a link and a code covers the most ground.

Once a code is used, the sale shows up under **Referrals** in the left sidebar, and the commission under **Rewards** once the program approves it. See [how you get paid](/help-center/affiliates/payouts) for what happens next.

## Promoting several programs at once

If you promote more than one brand, the Influencer dashboard at [influencers.referly.so](https://influencers.referly.so) collects every code in one place.

Open **Settings**, then **Personal Information**, then **Promo Codes**. Each program you have codes in gets its own section. Expand one and you get the same cards, copy buttons and create button as in that program's own portal, with the discount shown in that program's currency.

![influencer-promo-accordion](https://qnthgdfusotvjgaxpfie.supabase.co/storage/v1/object/public/public-assets/docs/uploads/1784823603412-219378-final-influencer-promo-accordion-1784823603292.png)

On **My Programs**, the **Promote** button on any program card also opens that program's code and link together, which is the fastest way to grab both without switching portals. More on that in [your programs](/help-center/affiliates/my-programs).
