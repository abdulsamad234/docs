The Referly API lets your own systems, a developer, or tools like [Zapier](/help-center/integrations/zapier) and [Make](/help-center/integrations/make) read and change your affiliate program's data without anyone logging in to the dashboard. This page explains which plans include it and what to do once you have it.

## Plans that include API access

| Plan | API access |
| --- | --- |
| Startup | Not included |
| Business | Included |
| Enterprise | Included |
| Agency, Agency Pro, and Agency Scale | Included |

[Webhooks](/help-center/settings/advanced/webhooks) come with the same plans. See [plans and features](/help-center/billing/plans-and-features) for everything else each plan includes.

<Note>
  If you're on a free trial of the Business plan, API access stays locked until you start your paid plan. Select **Start Paid Plan** on the **Subscription** screen (**Settings**, then **Billing**, then **Subscription**) to unlock it straight away.
</Note>

If an agency runs your program, whether you have API access depends on the plan your agency has given you. Ask your agency if you need it. See [for agencies](/help-center/agencies/overview).

## If your plan doesn't include it

On a plan without API access, the **Generate New Key** button on the **API Keys** screen is locked. Selecting it opens an upgrade prompt that names the plan you'd need.

If you move to a plan without API access after you've created keys, Referly refuses requests made with those keys until you're back on a plan that includes it. That also applies to tools that connect through the API, such as Zapier and Make. Your keys aren't deleted, so they work again as soon as you upgrade.

## Create an API key

Once your plan includes API access, open **Settings** from the left sidebar, go to **Advanced**, then select **API Keys** and select **Generate New Key**. Each key works for one affiliate program, so create one in every program you want to connect.

See [API keys](/help-center/settings/advanced/api-keys) for how to generate, copy, and delete keys safely.

## Hand over to your developer

Everything a developer needs to start making requests is in the developer documentation:

- [Authentication](/developer-documentation/api/authentication) shows how to send your key with each request.
- [Rate limits](/developer-documentation/api/rate-limits) explains how many requests a key can make. The limits apply per key and are the same on every plan that includes API access.
